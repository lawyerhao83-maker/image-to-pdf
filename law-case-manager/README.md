# 案件管理簿（Google 版）安裝說明

事務所共用的案件、開庭與期限管理系統。資料存放在事務所 Google 帳號的試算表裡，期日會自動同步到 Google 日曆，系統每天早上 8 點也會寄 Email 提醒。

- **費用**：不用額外付費，用的是事務所現有的 Google 帳號。
- **使用者**：同事用自己的 Google 帳號（免費的 Gmail 也可以）登入。
- **權限**：只有被「新增同事」加入的人能開啟。停用之後，對方就打不開了。

---

## 一、安裝（約 15 分鐘，只需做一次）

以下步驟都用**事務所的 Google 帳號**操作。

### 1. 建立試算表
1. 打開 <https://sheets.new>，建立一份空白試算表。
2. 把檔名改成「案件管理簿」。

### 2. 貼上程式
1. 在試算表的選單點 **擴充功能 → Apps Script**，會開啟程式編輯器。
2. 左上角把專案名稱改成「案件管理簿」。
3. **Code.gs**：把編輯器裡原本的內容全部刪掉，貼上本資料夾 `Code.gs` 的全部內容。
4. **Index.html**：點左側「檔案」旁邊的 **＋ → HTML**，檔名輸入 `Index`（不要加 .html），再貼上 `Index.html` 的全部內容。
5. **appsscript.json**：
   1. 點左側齒輪 **專案設定**，勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」。
   2. 回到編輯器，打開 `appsscript.json`，把內容換成本資料夾的 `appsscript.json`。
6. 按 **儲存**（磁碟圖示，或 Ctrl＋S）。

### 3. 初始化
1. 回到試算表並重新整理網頁，上方選單會多出 **「案件系統」**。
2. 點 **案件系統 → 初始化（第一次使用）**。
3. 第一次執行時，Google 會要求授權：
   1. 選擇事務所帳號。
   2. 如果出現「Google 尚未驗證這個應用程式」，點 **進階 → 前往「案件管理簿」（不安全）**。這是你自己寫的程式，只是沒送 Google 審查，所以會出現這個提示。
   3. 點 **允許**。
4. 授權完成後，**再點一次「初始化」**，並輸入你的姓名。

完成後系統會自動建立：
- 六個分頁：案件、期日、工作紀錄、人員、假日、操作記錄。
- 一個「事務所期日」Google 日曆。
- 兩個定時工作：每 10 分鐘同步一次日曆，以及每天早上 8 點寄出提醒信。

### 4. 發布成網頁
1. 回到 Apps Script 編輯器，點右上角 **部署 → 新增部署作業**。
2. 點齒輪，選 **網頁應用程式**，然後這樣設定：
   - 說明：第一版
   - **執行身分：存取網頁應用程式的使用者**
   - **具有存取權的使用者：所有擁有 Google 帳戶的使用者**
3. 點 **部署**，複製「網頁應用程式網址」（結尾是 `/exec`）。這就是系統網址。

> 這樣設定是安全的。網頁用的是使用者本人的身分執行，沒有被共用試算表的人，就算拿到網址，也讀不到任何資料。

### 5. 匯入假日
1. 點 **案件系統 → 匯入台灣假日**，先輸入今年，再做一次輸入明年。
2. 打開「假日」分頁，對照行政院人事行政總處公告的辦公日曆表核對：
   - 「類型」欄只有三種值：**放假**（期限會順延）、**補班**（視為上班日）、**請確認**（計算時不當作假日）。
   - 颱風假等臨時停班，請自己新增一列，類型填「放假」。
3. 假日表如果不完整，算出來的末日**只會偏早、不會偏晚**，不會因此錯過期限。

### 6. 新增同事
1. 點 **案件系統 → 新增同事**，依序輸入同事的 Google 帳號 Email、姓名、職稱。
2. 系統會自動做兩件事：把試算表共用給對方，以及把「事務所期日」日曆共用給對方。
3. 把系統網址傳給同事。

## 二、同事第一次使用

1. 打開系統網址，用自己的 Google 帳號登入。
2. Google 會要求授權，步驟和上面的「初始化」相同，按「進階 → 前往」再按「允許」，只需要做一次。
   - 授權畫面會列出試算表、日曆、Email 等權限。這是因為整個程式只能一起申請權限。實際上，同事使用時只會讀寫案件試算表；日曆同步和提醒信是由事務所帳號負責的。
3. **設定日曆提醒**：Google 日曆的提醒是每個人自己設定的。
   1. 打開 Google 日曆，在左側找到「事務所期日」，點 ⋮ → **設定與共用**。
   2. 在「活動通知」設定提醒，例如前 1 天、前 2 小時。
   3. 在「全天活動通知」也設定提醒，例如前 1 天上午 9 點。
   - 手機上的 Google 日曆 App 也會一起提醒。
4. 建議把網址加到手機桌面或瀏覽器書籤。

## 三、日常管理

| 要做的事 | 怎麼做 |
|---|---|
| 新人加入 | 案件系統 → 新增同事 |
| 同事離職 | 案件系統 → 停用同事（資料和紀錄會保留，對方立刻無法開啟） |
| 每年年底 | 案件系統 → 匯入台灣假日（匯入明年），再核對「假日」分頁 |
| 日曆沒更新 | 案件系統 → 立即同步日曆 |
| 測試提醒信 | 案件系統 → 寄一次今日提醒 |
| 查誰改了什麼 | 看「操作記錄」分頁 |
| 改壞了要還原 | 試算表 **檔案 → 版本記錄**，可以還原到任何一個時間點 |
| 備份 | 每月 **檔案 → 下載 → Microsoft Excel**，存一份到別處 |

### 修改程式之後
在 Apps Script 點 **部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署**。網址不會改變。

---

## 四、注意事項

- **請不要直接在試算表裡改資料或調整欄位名稱**，一律從系統網頁操作。直接改試算表不會留下操作記錄，也不會檢查同時編輯的衝突。欄位順序可以調整，但不要改標題名稱。
- **期限試算僅供參考。** 計算方式是：始日不算入（民法§120），末日遇假日順延（民法§122），可以自行加上在途期間。末日如果是補行上班日，系統會提醒你確認。特別規定和個案情況，請律師自行核對。
- **在日曆上直接修改期日，會被系統覆蓋。** 請回到系統裡修改。
- 加入成為編輯者的同事，技術上也能看到試算表和程式碼。請只加入事務所成員。
- 事務所帳號務必開啟**兩步驟驗證**，救援電話和救援信箱也要設定成事務所能掌握的。
- 系統規模：同時幾十人使用、幾千件案件都沒問題。每次儲存大約要 1～3 秒。

## 檔案說明

| 檔案 | 內容 |
|---|---|
| `Code.gs` | 後端：讀寫試算表、檢查同時編輯衝突、期限計算、日曆同步、提醒信、管理選單 |
| `Index.html` | 網頁介面：總覽、案件、期日、案件詳情、表單 |
| `appsscript.json` | 專案設定：時區、日曆進階服務、網頁權限 |
